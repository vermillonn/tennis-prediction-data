## Limits of this evidence

- `recorded_at` comes from the ledger host's clock; a hash chain fixes order and content, not time.
- A GitHub commit proves the checkpoint bytes were in that repository; its commit date is set by the client and the repository's administrators can rewrite or delete history (force pushes). It is publication, not trusted timestamping.
- An RFC 3161 token proves existence no later than its time only for the TSA the verifier chose to trust, and only for events at or before the checkpoint's sequence.
