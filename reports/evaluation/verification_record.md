## 4. Independent verification

Every package check recomputes from the inputs. The tampering matrix (tests):

| tampering | detected by |
|---|---|
| corrupted ledger export | `manifest` (hash mismatch) |
| altered outcome snapshot, manifest updated to match | `recompute` (results differ) |
| altered published metric in a report, manifest updated | `reports` (re-render differs) |
| altered `results.json`, manifest updated | `recompute` |
| unlisted file added | `manifest` |
| receipt evidence removed, manifest updated | `recompute` |
| RFC 3161 token removed, manifest updated | `recompute` |
| verification under different TSA trust anchors | `trust_anchors` (and results differ) |
| whole package replaced by a self-consistent forgery | only `--manifest-sha256` against an independently obtained reference |
