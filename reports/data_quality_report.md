## Source discrepancies

Match-file rank (as of `tournament_date`) versus the latest `atp_rankings_*.csv` entry published on or up to 14 days before `tournament_date`, per player appearance in validated matches. `missing_in_rankings_file` includes unranked players and periods without published rankings (1982, and intermittent coverage before 1985):

| comparison | player_appearances | median_ranking_age_days | max_days_list_published_after |
|---|---|---|---|
| equal | 299584 | 0.0 |  |
| both_missing | 77218 |  |  |
| equals_later_list | 10561 | 6.0 | 14 |
| missing_in_rankings_file | 8200 |  |  |
| missing_in_match_file | 2658 | 8.0 |  |
| different | 339 | 0.0 |  |

`equals_later_list`: the match-file rank equals the list published *after* `tournament_date` (lag below). A 1-2 day lag is an event recorded as starting on a weekend that used the following Monday's list: no result of the event itself is encoded, but the list was not yet public on the event's first day. A lag of 7+ days would mean the rank could include the event's own results; for a player whose rank did not move, an equal later rank can also be coincidence. Strictly point-in-time features should take ranks from the rankings files with `ranking_date <= tournament_date`.
