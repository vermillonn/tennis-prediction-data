- Test (out-of-sample) period: 2010-01-01 to 2026-12-31 (45191 matches). No parameter was chosen using test outcomes.

## Chronology (read this first)

The source has **no match dates**; only each event's start date. Matches are therefore grouped into weekly batches running from Saturday 00:00 to six days later, by `tournament_date`. All predictions in a batch use the ratings frozen at the batch start; results update ratings only when the batch closes. Multi-week events (levels G: 2 weeks; levels M with draw >= 96: 2 weeks; levels O: 2 weeks) update only when their last batch closes. A match's prediction therefore never uses its own result, nor any result from its own event or from later batches. Weekly batching is an approximation: ratings can be up to a week (two for long events) staler than a match-by-match replay with true dates would allow.

Within a batch close, all results are applied simultaneously from the frozen state (order-independent, zero-sum); see `docs/elo.md`.
