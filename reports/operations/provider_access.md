## Minimum action needed from the repository owner

Network access is set per environment (environment settings → Network access → allowed domains; https://code.claude.com/docs/en/cloud-environments#network-access). Credentials are added as environment variables of the environment and are never committed. Any one of the following unblocks the gap backfill:

1. **Licensed API (results + statistics + schedules + actual start).** For example Sportradar Tennis: allow `api.sportradar.com` and set `SPORTRADAR_API_KEY` (a trial key is limited and commercial use needs a contract). Similar for api-tennis.com (`api.api-tennis.com`, `API_TENNIS_KEY`) or RapidAPI (`tennisapi1.p.rapidapi.com`, `RAPIDAPI_KEY`). The response layouts are still unverified and must be checked against real responses before use (Phase 4A `NotVerifiedError`).
2. **Authorized file export.** Place a Sackmann-format CSV export you are licensed to use (for example from the TML website, if its terms permit) in the workspace and import it with `tennis-data prospective-import <file> --format sackmann_csv`, if its IDs are archive IDs. Otherwise convert it with the TML converter (ATP codes).
3. **Results-only source.** Allow `www.tennis-data.co.uk` for completed-match results (no serve statistics). Elo updates are possible; serve/return state would stay missing for the gap.

Hosts to allow for the probes above: `api.api-tennis.com`, `api.sportradar.com`, `stats.tennismylife.org`, `tennisapi1.p.rapidapi.com`, `tennisdata.app`, `www.tennis-data.co.uk`.
