# Feature dictionary (Phase 3A serve/return)

_Generated by `tennis-data features-docs` from `src/tennis_data/features/dictionary.py` for `config/features.toml`. Do not edit by hand; a test fails when it is stale._

Timestamp policy for every player feature: state frozen at the start of prediction_batch; observations released in earlier batches only. Tournament dates are event start dates; no match dates exist. Rates are point-weighted (sum won / sum played). Missing statistics are never treated as zero.

Player features are exported twice, `a_<name>` and `b_<name>` (Phase 1 winner-independent order).
